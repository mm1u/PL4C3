## About

PL4C3 is a surreal psychological horror game currently
prototyped in Python, with plans for a future 3D remake in Godot.

A text-based game about a place you don't recognize.

Question the Guide. Make choices. Pay attention.

Not everything you hear is true.

## Features

- Branching dialogue
- Multiple choices
- ASCII animations
- Sound effects
- Color-coded dialogue
- Multiple voices and dialogue styles
- Surreal horror atmosphere

## Built with

- Python
- Tkinter
- Colorama
- PyFiglet
- Playsound
- PyTTSX3

## Color guide

🟣 Magenta &rarr; PLACE \
🔵 Cyan &rarr; choices / interaction \
🟡 Yellow &rarr; player's dialogue \
🔴 Red &rarr; danger / errors / warnings \
⚪ White &rarr; narration
